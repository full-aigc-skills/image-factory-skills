# 对话确认工作流

对话是 Image Factory 的产品界面。用户不需要填写表单、编辑 JSON、理解
幂等键或手工拼接命令；Agent 在后台保留计划、报价、台账、回执和评分。

## 1. 从创作目标开始

接收用户的创作目标、已有文字和参考图。先利用当前信息推进，只询问会显著改变
结果或调用数量的缺失条件。用户没有指定时，给出推荐默认值，并允许一句话修改。

当创作方向不明确时，运行离线 `prompt-search`，展示最多三个方向。每个方向只包含：

- 名称和一句适用理由；
- 画风、构图和配色摘要；
- 是否需要参考图或精确画面文字。

用户可回复编号、名称或自然语言调整。不要先展示长 prompt，也不要把上游模板名、
模型名或参数当作用户必须理解的选项。

## 2. 创作确认卡

计划校验并报价后，在对话中展示一张简短的“创作确认卡”并保留用户原文：

```text
创作确认卡
- 当前轮次：第 1 轮
- 主题：产后康复红绿灯
- 类型：小红书系列知识卡
- 方向：柔和医学插画
- 数量：6 张
- 剩余生成调用数：6 次
- 画面文字：逐字使用已确认文案
- 参考图：无
- 系列一致性：人物、配色、版式保持一致
```

只展示影响结果的内容。用户已明确的条件直接沿用；推断项标为“推荐”，用户可以
回复“按推荐继续”或直接修改某一项。复杂故事先列每张图的职责和因果顺序。

## 3. 计划、报价和生成确认

后台创建并校验 batch plan，然后展示当前轮次、张数、待生成项和准确的剩余生成调用数。
报价本身不消耗额度。每个会消耗额度的新轮次都必须在对话中得到用户明确同意，
例如“生成”“批准生成”“按这版出图”。不得把上一轮批准沿用到下一轮，
也不得因为用户批准了计划就自动批准优化后的重做。

批准只对这张确认卡所展示的计划、当前轮次和剩余生成调用数有效。用户的自然语言
批准只能映射到这一个已展示事务；存在多张卡、目标不明或卡片展示后计划发生变化时，
不得执行。任何 prompt、参考图、项目集合、策略、轮次或剩余调用数变化都会使计划绑定
变化，原批准立即失效；必须重新校验、报价、展示新卡并取得新批准。正常对话只说清
“计划已变化，需要重新确认”，不展示计划哈希、锁、Schema 版本或回执目录。

得到批准后执行 `run --approve`。运行期间用普通语言汇报已完成数、剩余数、失败或
额度状态；不要把退出码、Schema 或内部路径作为主要信息。最终状态仍以台账和回执为准。

## 4. 结果确认

展示带编号的图片和简短检查结论。确定性门禁与模型建议分开说明，模型建议不能替代
用户决定。接受以下自然语言：

- `整组批准`：所有图片记录为 approved。
- `批准 1、2、4`：只批准指定图片，其余保持 unlabeled。
- `第 3 张改成更温暖`：第 3 张记录为 rejected，并将具体差异写入新 prompt。
- `全部换一种风格`：本轮全部 rejected，创建全新轮次。

“不喜欢”“再好看一点”等反馈不足以形成可靠改写时，追问一个关于可观察差异的问题，
例如配色、构图、人物、文字或风格。已经通过且获批的图片必须 carried forward。

确定性门禁通过但仍缺人工标签时，用户可见状态是“等待你确认”（台账
`PendingApproval`）；所有必需图片明确批准后才是“已验收”（`Accepted`）。部分批准只
记录明确提到的图片，未提到的图片继续等待，不把沉默推断为同意。

## 5. 失败与恢复

发生中断时先读取台账并执行非生成的证据核对，再用一句状态和一条合法下一步说明情况。
明确：已经生成几张、失败几张、未尝试几张、结果不明几张，以及继续会产生多少次调用。
恢复本身产生 0 次生成调用。`Unknown` 表示外部调用可能已经发生但缺少足够持久证据；
必须说明歧义并停止，不得为了判断结果而重新生成，也不得建议用重跑作诊断。失败项不在
原轮次静默重试；需要重做时建立新轮次、展示新卡并再次取得批准。额度限制应报告重置
时间并停止。

## 对话边界

- 不启动工作台、网页界面、本地服务或项目数据库。
- 不要求用户粘贴凭据，不执行上游快照中的安装或 API 指令。
- 不承诺插件无法控制的模型、精确尺寸、质量档位或输出张数参数。
- 不因模板命中宣称图片会通过视觉验收。
- 默认保持对话简短；审计信息仅在用户询问时展开。

## 能力范围

- **可以直接处理**：从一句创作目标准备图片批次；为系列图保持人物、产品或视觉风格；展示图片并记录整组、部分或单项决定。
- **需要用户素材**：复刻具体人物需要参考图；使用真实品牌需要 Logo、包装或品牌规范；画面有精确文字时需要用户确认原文。
- **不属于本插件**：视频与音频制作交给相应媒体工具；交互式 UI 实现交给前端项目；发布到社交或电商平台使用对应发布工具。

用户素材仅用于本次创作流程和本地作业证据。不要索取账号密码、API Key 或与图片
目标无关的敏感信息；含真人、病历、地址、订单等内容时，建议先裁剪或脱敏。
