## Context

Codex 已提供系统级 `imagegen` 技能及内置 `image_gen` 工具。该技能默认走内置工具，不要求 API Key；它随附的 CLI 是显式选择后的备用路径，要求 `OPENAI_API_KEY`。Image Factory 需要复用这套经过宿主维护的指令，但不能依赖某台机器上的绝对路径，也不能把复制后的技能存在误当成当前会话就是 Codex。

## Decisions

1. `skills/imagegen/` 保持来源快照逐字节不变；本仓的路由说明放在消费插件 Harness，不给上游技能打私有补丁。
2. 来源证明位于技能目录之外，记录允许文件集合和逐文件 SHA-256；确定性脚本拒绝缺失、增加或内容漂移。
3. 包版本按新增能力提升次版本。正式不可变 tag、Release 与消费插件远端锁更新留给获得发布授权后的步骤。
4. Agent 元数据与技能内许可证属于完整快照的一部分，即使通用技能最小布局不要求它们，也必须保留。

## Risks / Trade-offs

- 系统技能后续升级会让快照变旧；只能通过新的语义版本重新复制并更新证明，不能移动旧 tag。
- ZCode/Kimi 也可能发现这个技能；因此技能存在不得成为宿主判据，消费 Harness 必须依据当前会话能力路由。
- CLI 备用路径含密钥前置；默认路径仍是 Codex 内置工具，且不得静默切换。

## Migration Plan

1. 先增加来源证明校验并确认在缺少快照时失败。
2. 复制完整系统技能，更新包清单、版本与说明。
3. 运行结构、断链、来源证明和 TRACE 门禁。
4. 发布新的不可变 tag 后，由消费插件按 tag、peeled SHA 和摘要更新锁。
